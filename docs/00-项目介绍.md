# 00 · 项目介绍

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 定位与交付

面向短跑训练的视频辅助测量原型，交付 Android Flutter App 与电脑 Python 服务。当前默认以人工接触帧计算时间指标；自动姿态分析保留为实验入口。不是已完成专业设备对照验证的运动测量系统。

## 当前流程

固定侧面原始高帧率视频 → 上传 → 框选运动员与区间 → 人工标注左右脚接触事件 → 四项确认 → 时间报告 → 电脑数据集归档。完整操作见 [18](18-固定侧面人工确认计时.md) 和 [19](19-人物锁定.md)。

## 能力边界

人工路径只输出触地、腾空、步频、占空比，不推断阶段或空间指标，不生成标准偏差与训练处方。自动路径支持模型切换及保守目标关联，但空间标定、自动事件和身份准确率尚未验证。当前参考库条件不足，不能把没有建议解读为动作正常。

## 架构与版本

App 管理运动员、选视频、标注与展示；电脑负责解码、计算、规则和归档。App 1.1.1+3，算法 0.4.0，规则 0.3.0，契约 1.2.0，标准库 0.1.0。文档索引见 [目录](README.md)，后续验收见 [15](15-下一步与后续工作计划.md)。

旧版“立项/冻结/全自动指导”等设计承诺由当前实现说明取代，历史内容可通过 Git 历史追溯。
