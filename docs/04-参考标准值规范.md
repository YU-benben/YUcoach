# 04 · 参考标准值规范

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 参考库是什么

参考库保存有出处、适用人群和测量口径的研究/队内统计；建议库保存由明确条件触发的训练解释和练习。两者均不等于姿态模型权重。研究均值描述样本，不能直接当成每位运动员必须达到的合格值。

## 当前状态

[data/standards](../data/standards) 保留5条生产条目用于加载和审计，标准版本0.1.0。跑动条件未核实时按 unspecified 保存，因此不能进入自动判定。调研的11项候选值尚未导入。人工计时未分期，不触发标准值比较或训练处方。

## 入库流程

查原文 → 记录 DOI/稳定链接、表格/页码、样本量、人群和原始单位 → 核对2D/3D、事件、阶段、均值窗口、跑动负荷 → 独立复核 → 填写 YAML → 执行检查与匹配回归 → 更新库版本及变更依据。

均值±SD不能擅自转换为正常上下限；不同单位需显式换算并保留原值。未知条件不能为了恢复建议而猜填 unloaded。队内统计需说明采集设备、标注一致性和样本结构，不能由少量重复帧冒充多人样本。

## 匹配条件

指标、视角、阶段、性别、训练水平、专项、测量窗口、步次、跑动条件与负荷方案必须一致；文献限制年龄时还需已确认年龄匹配。未知不是通配，重复候选不自动取第一条，不能退回其他水平或 whole_run。完整字段与示例见 [17](17-参考值严格匹配.md) 和 [loader.py](../backend/standards/loader.py)。

## 建议审核

数值偏离不证明存在病因。建议必须有适用条件、依据、禁用条件和复核记录；当前练习映射没有完成效果验证。报告应说明未匹配原因，不用“无结论”替代“正常”。

版本说明：报告目前保留 `std_version=0.1.0`，生产YAML库与条目的版本标识为 `2026Q1`，两者尚未统一；复核历史结果时需同时核对实际参考文件，不把该旧报告字段视为完整库溯源。
