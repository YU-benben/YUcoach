# 09 · 报告与指导解析规范

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 结论如何产生

自动路径先计算Metric，再按严格条件查找唯一可比参考，规则检查可用性和偏差，最后填充既有解释及练习。不是语言模型凭视频自由生成诊断。实现见 [report.py](../backend/analysis/report.py)、[rules.py](../backend/analysis/rules.py) 和 [参考匹配](17-参考值严格匹配.md)。

默认人工路径直接从确认帧号计算4项时间指标，阶段标whole_run，不做标准值偏差或训练建议。即使某数值落在常见量级，也不能跳过人群和口径匹配。

## 报告必须说明

运动员与视频/任务标识、采集视角、原片时间基准、选定区间、人工或模型来源、版本、有效样本数、不可测原因。当前结构由契约约束，不能因为页面少显示字段就删除溯源数据。

人工报告只展示前12个原始事件画面，完整事件保存在review.json。框选备注说明身份核对来源，不能称为身份认证。质量分包含姿态和尺度缺失扣分，是旧覆盖评分，不是计时准确率。

## 措辞

“未找到可比参考/尚不能判断”与“动作正常”不同。“模型预测”“人工确认”“仪器对照实测”必须分清。训练建议要写适用条件和依据，不能把偏差写成病因、伤病诊断或承诺训练效果。

## 当前限制

旧自动空间结果尚未通过可靠标定与真实对照；没有完成真实高速多人跟踪准确率评估。生产参考库条件未核实，调研候选未自动导入。当前没有完整PDF导出与人工在线修订系统；旧设计中的承诺不代表已经交付。
