# 02 · 数据标准

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 当前采集协议

固定侧面，镜头尽量垂直跑动方向，不跟拍、不变焦，保证完整人体、鞋底与地面清晰；充足照明与短曝光比单纯提高分辨率更关键。至少 120 fps，推荐 240 fps，使用未变速、未补帧的原始文件。

当前选人流程要求可解码原片、120–1000 fps，以及恒定连续容器时间戳（相邻间隔与 1000/fps 相差不超过 2%）。这是文件时间基准检查，不证明相机真实采样率。30 fps 慢放视频不能因为播放看起来慢就用于高精度接触计时。

## 标注

先在一个清晰、无交叉的帧框住完整运动员，以该帧作为起始帧，选择更晚结束帧，两端包含。全程保留原视频零起始帧号，不重编号。

着地 TD：鞋底首次接触地面的帧。离地 TO：鞋底首次完全离开地面的帧。同脚 TD→TO 配对，相邻接触左右交替。至少两次完整接触，计算占空比还需要同脚下一次着地。首尾不完整接触可排除，内部不能漏标；边界模糊时更换素材，不猜测。

四项确认：原片时间基准、固定侧面、同一运动员、区间内无漏标。人工确认仅是标注来源，不等于通过独立复核的真值。

## 参考尺度与几何

人工路径完全不使用身高、腿长或跑道线推算空间距离。分道宽是横向尺度，不能直接充当纵向步长尺度；归一化 x/W、y/H 不能直接用于欧氏几何。未来空间测量需同平面标定、透视与镜头误差验证，再启用报告。

## 质量控制与归档

建议双人独立标注并复核边界分歧，记录标注者、复核状态和误差；这是后续数据治理工作，当前 App 没有完整双人审核系统。训练/验证/测试应按运动员及拍摄场次隔离。现有归档字段见 [20](20-数据管理与后续训练.md)。
