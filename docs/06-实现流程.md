# 06 · 实现流程

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 当前开发顺序

1. 保持默认人工计时可复核，先解决事件标注一致性与原片时间基准。
2. 收集经过复核、按运动员和场次隔离的数据，评估人物关联及事件误差。
3. 修复自动几何/尺度，逐项对照人工与标定结果。
4. 补齐采集条件与文献审核，再启用严格匹配的标准及建议。
5. 最后完善公网权限、持久任务、备份、发布签名及版本升级。

前两项已有功能入口，不代表数据标注集和评测已完成。人物锁定与模型切换已接通；不能再按旧计划将它们列为“尚未开始”。

## 一次修改的闭环

确认适用协议和失败行为 → 修改后端/契约/客户端 → 同步生成模型与fixture → 运行对应检查 → 检查真实输出 → 更新文档和版本 → 提交可追溯记录。不能只改报告文案掩盖计算缺陷。

## 验收依据

代码正确性与运动测量有效性分开。单元、契约和界面测试验证程序；人工多标注者、真实高速视频与测力台等对照验证测量。当前后者未完成。详细待办与阶段出口见 [15](15-下一步与后续工作计划.md)。
