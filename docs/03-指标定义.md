# 03 · 指标定义

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 当前可信路径的定义

令 f 为已确认的原始帧率，TD 为着地帧，TO 为同脚离地帧。

| 指标 | 定义 | 单位 |
|---|---|---|
| ground_contact_time | (TO−TD)×1000/f | ms |
| flight_time | (下一对侧 TD−当前 TO)×1000/f | ms |
| step_frequency | 60000 / 相邻交替 TD 间隔的平均毫秒数 | steps/min |
| duty_factor | (TO−TD) / (同脚下一 TD−当前 TD) | ratio |

占空比分母是同脚完整周期，不能用左右交替的一步时间。步频采用总步间隔数/总时长的汇总定义；不报告与该定义不一致的标准差。n 是各项可用接触/间隔/周期数，不是视频帧数。

240 fps 示例：左 TD0/TO24，右 TD48/TO72，左 TD96/TO120；接触100ms、腾空100ms、步频300步/分、占空比0.25（仅1个完整同脚周期）。

所有时间指标归入 whole_run（所选区间未分期），不自动比较文献阶段均值。其他指标保留数据不足状态而非填0。细节见 [18](18-固定侧面人工确认计时.md)。

## 误差与限制

120/240 fps 单帧间隔分别8.333/4.167ms；若每个边界误差±1帧，时长最坏误差±16.667/±8.333ms。这是条件界限，不是实测准确率。误认人物、漏接触和变速可产生更大误差。

## 自动指标与几何规范

[metrics_base.py](../backend/analysis/metrics_base.py) 的 METRIC_SPECS 是20项旧自动指标注册表，包括时间、侧面角度与位移、正背面骨盆/膝/支撑宽度等。规格内可靠性等级与最低帧率是设计元数据，不是当前实现的精度认证。人工路径仅启用上表4项。

空间角度应在等比例像素或标定坐标计算：关节角使用三点夹角，线段方向使用 atan2 并声明参考轴与符号；不能用各自除以W/H后的坐标直接量角。事件角必须取正确侧、正确阶段和正确事件，不能以无限距离最近帧代替。单目投影无法唯一恢复真实三维骨盆旋转。

已知旧自动路径尚有归一化几何、尺度方向、接触极性、支撑中期、帧间隔与占空比等问题，见 [05](05-模型与算法实现规范.md)。审计不能等同于完成修复。
