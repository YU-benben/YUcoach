# 08 · App 功能与交互规范

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 当前交互

App 提供账号、运动员、视频分析与报告等界面，手机端不做姿态推理。上传页默认人工计时；关闭默认开关才显示实验模型选择。

操作顺序：选运动员/原视频 → 填采集信息 → 上传 → 框人并选起止帧 → 人工事件页（默认模式）→ 四项确认 → 提交 → 查询进度 → 报告。服务、手机需使用匹配的新版本。

## 选人和标注

原图缩放后按实际图像区域映射选框坐标，留白不能作为视频坐标。移动到其他帧不显示静止旧框；重新框选重置区间。标注支持±1/±10帧、滑条、放大、事件删除与跳回。标注必须位于选定区间。

框选和人工标注本身不扣额度，取消不提交分析。服务端合法请求通过校验后扣额度；跟踪运行失败目前不自动退回。

## 报告展示规则

数值、不可用于判定、数据不足应有不同文案。缺失用“无法测量/待补齐”，不能以0或“正常”代替。人工模式显示原始事件画面和时间指标，不能画虚构骨架、角度或标准差异。

报告质量分是旧整份覆盖评分，不能显示为人工计时准确率。空结论应解释没有可比参考或数据不足。详见 [09](09-报告与指导解析规范.md)。
