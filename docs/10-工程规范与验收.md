# 10 · 工程规范与验收

更新：2026-10-16。本文描述当前实现；未来工作明确标为待完成。

## 质量门与可复现命令

在仓库根目录执行：

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q -m "not slow"
.\.venv\Scripts\python.exe scripts/check_contracts.py --dir samples/fixtures --sync-mobile
.\.venv\Scripts\python.exe scripts/check_schema_consistency.py
.\.venv\Scripts\python.exe scripts/gen_models.py --check
.\.venv\Scripts\python.exe scripts/check_standards.py
```

在mobile目录执行flutter analyze与flutter test，发布前flutter build apk --release。[check_all.py](../scripts/check_all.py)另包含GPU、权重、性能和旧自动指标检查，依赖开发机环境；不能将GPU检查作为人工计时最低要求，也不能把合成测试通过当作测量精度合格。兼容性快照与覆盖率门仍有预留项。

## 关键回归

时间公式与同脚分母、非法标注不扣额度、原图坐标框选、原始帧号和区间约束、旁人更大/换序/交叉/消失/跳转/断帧、丢失禁止报告、两个模型接入、严格参考匹配以及无结论不宣称正常。

## 契约与代码

Schema先行，使用gen_models.py更新Dart生成物，不手工改生成枚举。原始fixture在samples/fixtures，App资产通过校验工具同步。错误分参数错误、素材不足与运行失败，不能静默换模型或混人后继续报告。

## 数据与发布

账号、运动员视频、标注、缓存权重和本地产物不进Git。特别注意.cache/accounts.json与data/manual_timing并非可随意删除的缓存。服务仍为可信局域网原型，公网部署需补齐身份授权、传输与持久存储。

App版本在mobile/pubspec.yaml；修改后重建APK并核对versionName/versionCode。同签名升级；推送源码与发布安装包是不同动作。验收需记录实际执行结果、真实样例、失败范围和产物版本，不能引用过期测试数字冒充当前结果。
